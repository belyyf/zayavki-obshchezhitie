# Доска заявок «Общежитие» — Модуль 1 (React)

Это мой итоговый проект по первому модулю. Я прошел главы 1.1–1.7, собрал базовую доску заявок на Vite + React + TypeScript, а затем переделал её под вариант «Общежитие» (заявки жильцов коменданту).

Проект полностью готов к защите: все механизмы работают, данные сохраняются, код проходит сборку и линтер.

## Что переделано под вариант «Общежитие»
Согласно заданию, механизмы доски (состояние, `map`, обработчики, сохранение, отправка) остались без изменений — я менял только данные и тексты.
- **Шапка:** Заголовок «Заявки в общежитие», подпись «заявки жильцов коменданту».
- **Поле места:** Переименовано в «Комната», в карточках сокращение «комн.».
- **Категории:** Сантехника, Электрика, Мебель, Интернет.
- **Начальные данные:** 5 заявок (протекает кран, не работает розетка, сломалась дверца шкафа и т.д.).
- **Хранилище:** Ключ в `localStorage` изменен на `'zayavki-obshchezhitie'`, чтобы доска не подхватила старые заявки ИТ-отдела.

## Инструкция по запуску
1. Перейдите в папку с проектом:
   ```bash
   cd zayavki
2. Установите зависимости (если папки node_modules нет):
  npm install
3. Запустите сервер разработки:
   npm run dev
4. Откройте в браузере http://localhost:5173.
   (Остановить сервер можно сочетанием Ctrl+C в терминале).

Доступные команды

npm run dev	- Запуск сервера для разработки (с HMR)

npm run build	- Проверка типов (tsc) и сборка проекта в папку dist

npm run lint - Проверка кода линтером Oxlint

npm run preview	- Локальный просмотр уже собранной версии

Как сбросить данные
Если нужно вернуть доску к исходным 5 заявкам (например, перед показом преподавателю):

Откройте DevTools в браузере (F12) -> вкладка Application.

Слева выберите Local Storage -> http://localhost:5173.

Удалите ключ zayavki-obshchezhitie.

Обновите страницу (F5).

Автоматизация (n8n + Telegram)
Код отправки заявки находится в src/notify.ts. Он отправляет POST-запрос на http://localhost:5678/webhook/zayavka.
Если сервер n8n не запущен, доска продолжает работать, но выводит предупреждение «уведомление не отправлено». Настройка n8n описана в отдельной папке автоматизации (если прилагается).
